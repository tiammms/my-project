# Проверка правил, набор v5 (05.11.2026): казахская речь и пересказ звонка

Зачем: в приложении появились «Проверка голосового сообщения» и «Расскажите, что вам сказали» (пересказ звонка
голосом после разговора). Пересказ звучит иначе, чем речь мошенника: «попросили продиктовать код»,
«сказал, что из полиции», «кодты сұрады». Кроме того, казахская речь на прошлом контрольном наборе (v4) давала 16 из 28.

Два файла, фразы в стиле распознавания речи (строчные буквы, без знаков препинания):
- `holdout.csv`: 114 фраз (казахская речь 30 + 30, пересказ по-русски 15 + 15, пересказ по-казахски 12 + 12).
  Записан и измерен **до** изменения правил (`holdout_before.json`), правила по нему не подгонялись. После изменений
  измерен один раз (`holdout_after.json`);
- `dev.csv`: 130 других фраз тех же видов. На ошибках этого набора (и на ошибках прошлого контрольного набора v4,
  который уже был использован) дорабатывались правила.

Предупреждение = средний или высокий риск.

Контрольный набор (не использовался для настройки):

| | до | после |
|---|---|---|
| Казахская речь: мошеннические фразы с предупреждением | 21 из 30 | **25 из 30** |
| Пересказ по-русски | 10 из 15 | **11 из 15** |
| Пересказ по-казахски | 6 из 12 | **10 из 12** |
| Всего | 37 из 57 | **46 из 57** |
| Ложные предупреждения на обычных фразах | 0 из 57 | **0 из 57** |

Рабочий набор: 36 из 65 → 60 из 65, ложных 0 из 65. Прошлые наборы не ухудшились: v1 30 из 30, v2 29 из 30,
v3 34 из 34, v4 рабочий 23 из 25, ложных 0. Прошлый контрольный v4 после изменений — 20 из 28 (раньше 16 из 28),
но он уже использовался для настройки, поэтому это не независимая оценка.

Выводы:
- на новом контрольном наборе рост меньше, чем на рабочем (46 из 57 против 60 из 65): правила-шаблоны по-прежнему
  плохо переносятся на новые формулировки;
- часть пропусков намеренная: одна фраза с одним приёмом («торопил», «уақыт аз», «деп қорқытты») не даёт
  предупреждения — в реальном разговоре риск складывается из нескольких фраз.

Ограничения:
- оба набора написаны одним автором (тем же, кто писал правила), это не записи настоящих звонков;
- казахские фразы нужно проверить носителю языка;
- 114 фраз в контрольном наборе — мало для точных процентов;
- этот контрольный набор теперь использован. Для следующей проверки нужен новый.

Запуск: `python -m experiments.text_eval_v5.run_eval dev` или `... holdout` из корня репозитория.
