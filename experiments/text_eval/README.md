# Проверка правил анализа текста на тестовом наборе команды

`cases.csv` — 60 фраз (30 типичных приёмов мошенников, 30 обычных сообщений; русский, казахский, английский).
Фразы **написаны командой**, это не записи реальных звонков. Набор зафиксирован 19.10.2026 и не используется
для подбора правил: если правила улучшать, для новой оценки нужен новый набор.

Запуск из корня репозитория: `python -m experiments.text_eval.run_eval` → `results.json`.
«Предупреждение» = уровень MEDIUM или HIGH.

Результат (19.10.2026): предупреждение на 20 из 30 мошеннических фраз (HIGH — 11), ложные предупреждения на 2 из 30 обычных.
Пропущены: «родственник в беде» без слов о коде, инвестиции, оплата доставки по ссылке без адреса, часть казахских фраз.
Ложные: SMS банка с кодом (вне звонка), «пароль от вайфая».

Повторный запуск после добавления правил для пропущенных схем (22.10.2026, `results.json`): предупреждение на 24 из 30 (HIGH — 13), ложные — 2 из 30.
Этот набор уже использовался при разработке, поэтому новые правила оценивались на отдельном наборе `experiments/text_eval_v2`.
