# Проверка правил на наборе v2

Набор v2 (`cases.csv`, 60 фраз: 30 мошеннических и 30 обычных, рус/каз/англ) написан командой 22.10.2026
**до** того, как в правила были добавлены новые категории. Фразы составлены по описаниям схем,
это не записи настоящих звонков.

Новые категории (одинаковые в `backend/app/biometrics/scam_text.py`, `android/.../core/ScamAnalyzer.kt`, `ios/Core/ScamAnalyzer.swift`):
«близкий в беде», «просят прислать деньги», «обещают гарантированный доход», «выигрыш или проблема с посылкой»,
«просят оплатить налог, пошлину или доставку», а также фразы «оставайтесь на линии», «не отключайтесь».

| | До изменений (`results_before.json`) | После (`results_after.json`) |
|---|---|---|
| Мошеннические фразы с предупреждением (средний или высокий риск) | 11 из 30 | 29 из 30 |
| Из них высокий риск | 2 из 30 | 17 из 30 |
| Ложные предупреждения на обычных фразах | 0 из 30 | 0 из 30 |

Ограничения, которые нужно называть вместе с цифрами:
- правила писали те же люди, которые составили набор v2 и видели его; поэтому результат «после» завышен.
  Независимая оценка требует набора, который напишут другие люди и который не будет использоваться для правок;
- 60 коротких фраз — слишком мало для статистических выводов;
- на старом наборе v1 после изменений: 24 из 30 мошеннических фраз с предупреждением (было 20), ложных предупреждений 2 из 30 (без изменений).
  Набор v1 уже использовался при разработке, поэтому независимой проверкой он не является.

Запуск: `python -m experiments.text_eval_v2.run_eval` из корня репозитория.
