# Публичный набор: фразы мошенников из публикаций (05.11.2026)

Зачем: все прошлые наборы писала команда, та же, что писала правила. Здесь фразы взяты из публикаций полиции,
МВД РК, Банка России и финансовых СМИ (`phrases.csv`, у каждой строки ссылка на источник). Изменения только
«как после распознавания речи»: строчные буквы, без знаков препинания.

48 фраз: 32 на русском, 16 на казахском. Набор сохранён отдельным коммитом **до** измерения.

Каждая фраза — одна реплика из звонка, поэтому две меры:
- **предупреждение** — средний или высокий риск уже от этой одной реплики;
- **приём распознан** — найден хотя бы один приём мошенников (он попадает в причины в отчёте о звонке).

Одна реплика с одним «мягким» приёмом («не кладите трубку», «никому не рассказывайте», «возбуждено уголовное дело»)
по замыслу не даёт предупреждения: в реальном разговоре риск складывается из нескольких реплик. Так сделано, чтобы
не было ложных тревог на обычных разговорах.

| | предупреждение | приём распознан |
|---|---|---|
| **До изменения правил (независимая оценка)** | **14 из 48** | **27 из 48** |
| — русский | 10 из 32 | 19 из 32 |
| — казахский | 4 из 16 | 8 из 16 |
| После доработки правил по ошибкам этого набора | 20 из 48 | 46 из 48 |

Независимая оценка — только строка «до». После доработки набор уже использован для настройки, цифры «после» — не
независимые. Для следующей честной проверки нужен новый набор из публикаций.

Ложные тревоги после доработки не появились: v1 0 из 30, v2 0 из 30, v3 0 из 30, v4 0 из 22 и 0 из 28,
v5 0 из 65 и 0 из 57. Мошеннические фразы прошлых наборов: 30 из 30, 29 из 30, 34 из 34, v4 23 из 25 и 21 из 28,
v5 60 из 65 и 46 из 57.

Выводы:
- на чужих формулировках правила, написанные под свои фразы, узнавали приём лишь в 27 из 48 реплик: это главный
  честный результат. Шаблоны плохо переносятся на новые слова, особенно казахские;
- после доработки приём распознаётся почти везде, но одна реплика редко даёт предупреждение — это намеренный выбор
  в пользу отсутствия ложных тревог;
- нормальных фраз из публикаций нет, ложные тревоги по-прежнему измерены на наборах команды.

Запуск: `python -m experiments.text_eval_public.run_eval` из корня репозитория.
