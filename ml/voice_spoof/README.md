# Проверка «синтезированный ли голос» (экспериментально)

Небольшая модель, которая по 4 секундам звука оценивает, похож ли голос на синтезированный (робот, синтезатор речи, ИИ).
Работает на телефоне без интернета. Модель встроена в Android-приложение: `android/app/src/main/assets/voice/`.

**Чего модель не делает.** Она не определяет, кто говорит, и не говорит, мошенник ли человек.
Банки тоже звонят роботом. Модель не проверялась на клонировании голоса конкретного человека и на настоящих звонках.

## Как устроено

- Модель: `model.py`. Спектрограмма считается внутри сети (STFT в виде свёртки), дальше 4 свёрточных блока.
  Около 62 тысяч параметров, файл ONNX 1,3 МБ. На вход 64 600 отсчётов при 16 кГц (4,04 с).
- В приложении (`core/SyntheticVoice.kt`) звук режется на куски по 4 секунды, тишина пропускается.
  Предупреждение появляется, только если похожими на синтезированные оказались **не меньше 2 кусков и не меньше 30 %**
  кусков с речью. Микрофон слышит и владельца телефона, а одиночный кусок может дать ложную тревогу.
- Сама по себе проверка даёт средний риск. Вместе с фразами мошенников или кодом из SMS — высокий.
- Файл модели сверяется с SHA-256 из `model.json` до загрузки.

## Данные (`data.py`, собираются в CI)

| | Обучение | Проверка |
|---|---|---|
| Живая речь | FLEURS dev (Google, CC BY 4.0): русский, казахский, английский | FLEURS test: другие записи и люди |
| Piper (нейросетевой синтез) | голоса denis, irina, issai, lessac, amy, libritts_r (900+ дикторов) | **другие** голоса: dmitri, ruslan, iseke, raya, ryan, alan |
| eSpeak NG («робот») | варианты голоса default, m3, f2 | **другие** варианты: m7, f4, klatt |
| MMS-TTS (Meta) | 120 фраз на язык | другие фразы |
| Silero TTS | не используется | **синтезатор, которого модель не видела** (русский, английский) |

Синтезаторы произносят те же предложения, что читают люди в FLEURS. Поэтому модель не может отличать классы
по содержанию фраз. Тишина по краям обрезается у всех записей. Уровень громкости и шум меняются одинаково для обоих классов.

«Телефонный» вариант звука (`channel.py`) имитирует то, что приложение слышит на громкой связи:
- полоса 300–3400 Гц и 8 кГц, кодек G.711;
- маленький динамик, эхо комнаты, шум, разная громкость.

## Результаты (CI, запуск 40589116688; полные цифры: `results/metrics.json`)

Порог выбран заранее на отдельной проверочной части: около 2 % ложных тревог на живой речи в «телефонном» звуке.
На тестовых данных он не менялся. Цифры даны для **одного куска в 4 секунды**.

| | Чистый звук | Через «телефон» |
|---|---|---|
| Ложные тревоги на живой речи других людей | 0,4 % | 3,9 % (казахский: 9,2 %) |
| eSpeak («робот»), незнакомые варианты | 100 % | 77 % |
| Piper, незнакомые голоса | 83 % | 43 % |
| MMS-TTS, другие фразы | 99,6 % | 44 % |
| Silero — синтезатор, не встречавшийся в обучении | 97 % | 15 % |

Как это понимать:
- На чистом звуке модель хорошо отличает синтез от живой речи, в том числе синтезатор, которого не видела при обучении.
- Через громкую связь и кодек точность сильно падает. Роботизированный голос (eSpeak) модель узнаёт в 3 случаях из 4.
  Современный нейросетевой синтез — меньше чем в половине случаев. Незнакомый синтезатор (Silero) — в 15 %.
- На живой речи бывают ложные тревоги, особенно на казахском. Поэтому в приложении предупреждение
  появляется только при нескольких подозрительных кусках и называется «экспериментальная проверка, может ошибаться».
- Проверено только на смоделированном телефонном канале. На настоящих звонках не проверено.
  Клонирование голоса конкретного человека не проверялось: такого синтезатора в данных нет.

Для сравнения: исходная открытая модель AASIST-L без дообучения на этих же данных почти не различала классы.
Её равная ошибка (EER) на чистом звуке: Piper 50 %, Silero 49 %, MMS 35 %, eSpeak 16 %.
Дообучить её на процессоре CI за отведённое время не удалось: один проход по данным занимал 42 минуты.
Поэтому сделана своя модель поменьше.

## Как пересобрать

Workflow `.github/workflows/voice-model.yml` скачивает данные, генерирует синтезированную речь и обучает модель.
Он проверяет модель и экспортирует ONNX (сверяя результат с PyTorch), а результаты кладёт в ветку `voice-model-results`.
Чтобы обучить заново, удалите `weights/saqtan_voice.pth`. Если файл есть, скрипт только проверяет эти веса.

  Silero (CC BY-NC-SA) использовался только для проверки.
- Код и модель обучены с нуля в этом проекте. Код AASIST (MIT) использовался только для сравнения.
