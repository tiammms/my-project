# Сценарий видео-демо (≈ 80 секунд)

**Подготовка:** `python -m backend.app.main` → откройте http://127.0.0.1:8000. Для чистого журнала перед записью удалите `backend/data/`. Интернет не нужен: всё работает локально. Только Swagger UI (`/docs`) грузит стили из CDN, поэтому в видео его не показываем.
**Запасной вариант на все кадры:** скриншоты в `docs/screenshots/` (1–9) и слайд 7 презентации. Их можно переснять командой `node scripts/e2e_check.mjs`.

**Если что-то пошло не так во время записи:**
- Страница пишет «Backend is not reachable» → перезапустите `python -m backend.app.main`.
- Порт 8000 занят → `uvicorn backend.app.main:app --port 8010` и откройте :8010.
- Демо запускалось много раз и журнал «засорился» → остановите сервер, удалите `backend/data/` и запустите снова.
