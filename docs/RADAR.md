# Радар схем (прототип)

Простыми словами: телефоны с Saqtan по желанию пользователя отправляют обезличенные подозрительные фразы, сервер
раз в день отдаёт их Gemini, Gemini группирует их в схемы и находит новые, человек проверяет черновик, после чего
обновляются правила для всех, а банки получают сводку.

**Статус:** готова серверная часть и демо. Отправка фраз из Android-приложения ещё не сделана (нужен сервер в
интернете и экран согласия в приложении). На защите это «прототип / следующий шаг», не готовая функция.

## Демо за минуту (Windows)

1. Один раз: Пуск → «Изменение переменных среды текущего пользователя» → Создать: имя `GEMINI_API_KEY`, значение — ключ.
2. Двойной щелчок по `radar_demo_windows.bat` в корне проекта.
3. Скрипт берёт 48 настоящих фраз мошенников из публикаций МВД РК, банков и СМИ
   (`experiments/text_eval_public/phrases.csv`), обезличивает их, отправляет в Gemini и открывает сводку
   `backend/data/radar_report.html`.

Нужен только Python 3.10+; ничего не устанавливается.

## Как устроено

| Часть | Файл | Что делает |
|---|---|---|
| Обезличивание | `backend/app/radar/anonymize.py` | убирает номера телефонов, карт, счетов, ИИН, почту, суммы, коды, имена; у ссылки оставляет только домен |
| Хранение | `backend/app/radar/store.py` | SQLite `backend/data/radar.db`, фразы старше 30 дней удаляются |
| Gemini | `backend/app/radar/gemini.py` | ключ из `GEMINI_API_KEY`, только в заголовке `x-goog-api-key`, вычищается из ошибок |
| Анализ | `backend/app/radar/analyze.py` | промпт, JSON-схема ответа, проверка ответа (только реальные номера фраз, лимиты длины) |
| Сводка | `backend/app/radar/report.py` | HTML-черновик, весь текст экранирован |
| API | `backend/app/api/radar_routes.py` | `POST /api/v1/radar/report`, `GET /api/v1/radar/status`, `POST /api/v1/radar/analyze` и `GET /api/v1/radar/summary` (оба с `X-Admin-Token`) |

## Безопасность и конфиденциальность

- Ключ только на сервере, в переменной среды. Не в приложении, не в git, не в `.env` внутри OneDrive.
- Фразы обезличиваются на сервере (и будут обезличиваться на телефоне до отправки). Аудио и картинки не отправляются.
- Фразы — недоверенные данные: в промпте они внутри маркеров, модели запрещено выполнять инструкции из них,
  ответ проверяется по схеме. Результат — черновик, его проверяет человек.
- На платном тарифе Gemini API Google не использует запросы для обучения, но хранит их до 55 дней для проверки на
  нарушения (условия Gemini API). Поэтому туда уходит только обезличенный текст.
- Ограничения обезличивания: имена ищутся по заглавной букве, редкие случаи («Айгүл апа, …» в начале фразы)
  могут не распознаться. Поэтому отправка будет только по согласию и с предпросмотром того, что уйдёт.

Тесты: `python -m unittest backend.tests.test_radar` (без сети, Gemini подменяется).
