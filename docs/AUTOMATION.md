# Автоматическая защита звонков (Android)

После первой настройки (разрешения, роль «Определитель номера и спам», доступ к уведомлениям, модель речи)
Saqtan выполняет проверки сам, без открытия приложения.

## Цепочка для одного звонка

| Шаг | Что происходит | Где в коде |
|---|---|---|
| 1. Событие звонка | Обычный звонок: `CallScreeningService` (до ответа) и `PHONE_STATE`. Звонок в WhatsApp/Telegram/Viber: уведомление мессенджера (`NotificationListenerService`) | `call/Calls.kt`, `notify/MessengerListener.kt` |
| 2. Проверка номера | Скрытый, международный, нет в контактах, частые звонки, отметки пользователя, недавние подозрительные сообщения с этого номера, внешние источники (если подключены) | `core/CallRisk.kt`, `CallTracker.withReputation` |
| 3. Предупреждение до ответа | Окно поверх экрана звонка с причинами и советами; запись в историю | `alert/Warnings.kt` |
| 4. После ответа | Автоанализ речи (включён по умолчанию): приложение на секунду открывается, запускает микрофонную службу и возвращает экран звонка. Если запустить нельзя — причина записывается в отчёт | `CallTracker.onOffhook`, `listen/Listen.kt` |
| 5. Во время звонка | SMS с кодом от незнакомого номера → тревога «Возможное мошенничество»; фразы мошенников в речи → предупреждение с цитатой | `sms/SmsReceiver.kt`, `core/LiveMonitor.kt` |
| 6. Конец звонка | Отчёт: уровень риска, что найдено, что проверялось и что НЕ проверялось; запись в историю («Отчёт о звонке») и уведомление | `call/CallSessions.kt`, `core/CallSession.kt` |
| 7. Действия из уведомления | Кнопки «Отметить номер», «Позвонить близкому», «Позвонить в банк» (если номера заданы в настройках); после спокойного отчёта — «Номер надёжный». Звонок не совершается сам: открывается набор номера | `call/ReportActions.kt` |

Звонки с номерами из контактов не проверяются и не записываются.

## Точки подключения моделей и сервисов

| Интерфейс | Назначение | Сейчас |
|---|---|---|
| `ReputationSource` (`ReputationSources.remote`) | База мошеннических номеров банка, оператора или Антифрод-центра | Не подключена: нет доступного API; фиктивный сервис не создавался. В отчёте написано «не подключена» |
| `SyntheticVoiceDetector` | Обнаружение синтетического / клонированного голоса по PCM 16 кГц | `NotConnected`: нет проверенной открытой модели для телефонного качества звука |
| `ScamTextClassifier` | Классификатор речевых сценариев | `RuleBased` (правила, 12 категорий, рус/каз/англ; проверка на наборе v2 — `experiments/text_eval_v2`); обученную модель можно подставить вместо него |
| `SpeechModels` / `SpeechToText` | Распознавание речи на телефоне | Vosk, модели скачиваются один раз (рус 45 МБ, каз 42 МБ, англ 40 МБ) |
| `VoiceRiskAnalyzer` | Модуль анализа речи: классификатор + экспериментальный детектор синтетического голоса, причины с цитатами | Работает на транскриптах; проверен на 10 размеченных фразах. Синтетический голос сам по себе не может дать высокий риск |
| `RiskEngine` | Единая оценка 0–100: сигналы с достоверностью, список непроверенного, настраиваемые пороги (по умолчанию 30 / 70) | Используется для номера и речи; пороги проверены тестами |
| `LocalReputation` | Локальная репутация номера: ваши отметки и прошлые отчёты о звонках с этого номера | Работает на телефоне, без сети. Отметка «надёжный» всегда сильнее |

## Ограничения платформ

| Ограничение | Причина | Ближайший законный вариант |
|---|---|---|
| Звук собеседника в обычном звонке | С Android 10 источник `VOICE_CALL` доступен только системным приложениям | Микрофон при громкой связи; если телефон отдаёт тишину, это видно в отчёте |
| Звук звонков WhatsApp и других мессенджеров | Аудио шифруется и не отдаётся другим приложениям | Проверка номера по уведомлению, связь с подозрительными сообщениями, SMS-код во время звонка |
| Автозапуск микрофона в фоне | Android 14+ не даёт запускать микрофонную службу из фона | Приложение на секунду выходит на передний план (разрешение «поверх других окон»), затем возвращает экран звонка |
| Камера во время звонков | Тайное включение запрещено и не делается | Проверка видеозвонка только по кнопке, с подтверждением записи экрана |
| iPhone | iOS не даёт приложениям видеть звонки, их звук и SMS во время разговора | Фильтр SMS от незнакомцев (`ILMessageFilterExtension`), подпись отмеченных номеров (`CallDirectory`), ручная проверка текста — см. `docs/IOS.md` |

## Как проверено

| Что | Как | Статус |
|---|---|---|
| Логика цепочки: мошеннический звонок с кодом и фразами, обычный звонок, пропущенный, мессенджер после подозрительного сообщения, тишина, «не проверялось» | Юнит-тесты `CallSessionTest` (10 тестов) | Проходят |
| Звонок + SMS-код → тревога → отчёт «Возможное мошенничество» после завершения, без открытия приложения | Эмулятор Android 14 в CI: настоящий входящий звонок и SMS, проверка уведомления (`shots/asserts.txt`) | Проходит (21–22.10.2026) |
| Отчёт после пропущенного звонка | Тот же эмулятор | Проходит (22.10.2026) |
| Локальная репутация: повторный звонок с номера, который раньше получил отчёт «высокий риск» | Тот же эмулятор, журнал `shots/calls.txt` | Работает: второй звонок сразу оценён как высокий риск |
| Работа на реальных телефонах разных производителей | — | Не проверялось |
