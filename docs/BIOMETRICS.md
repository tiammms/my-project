# Модуль «Биометрия и звонки»

Модуль добавлен в существующий NeuroShield. Транзакционная модель, граф, дашборд переводов и все материалы защиты остались без изменений. Код модуля лежит в `backend/app/biometrics/` и `backend/app/api/bio_routes.py`, страницы — `frontend/src/pages/{BioHome,FaceCheck,VoiceCheck,Combined,BioHistory,PrivacyPage}.tsx`.

## Что реализовано

|---|---|---|---|

## Чего нет и почему

- **Детектор синтезированного голоса.** Открытые модели (AASIST, RawNet2 и др., обученные на ASVspoof 2019) плохо переносятся на современные системы клонирования голоса. Их «вероятность подделки» вводила бы пользователя в заблуждение. Поэтому проверка показывает «не подключено». Варианты подключения:
  1. API поставщика детекции дипфейков голоса (нужен ключ и договор об обработке данных);
  2. своя модель, обученная и проверенная на свежих данных (ASVspoof 5, In-the-Wild), с опубликованным EER.
  Место подключения — `registry.SYNTHETIC_VOICE_STATUS` и `_voice_result` в `bio_routes.py`.
- **Пассивная защита от подмены (anti-spoofing по одному кадру).** Не подключена по той же причине: нужна модель, проверенная на атаках с экрана и печати. Сейчас защита активная (повороты головы).
- **Ограничения проверки живости.** Она не защищает от объёмной маски, дипфейка в реальном времени через виртуальную камеру и от принуждения. Это написано в каждом результате.
- **Точность на реальных людях не измерялась.** Пороги SFace взяты из документации OpenCV. Пороги поворота (0,14 и 0,09 в межзрачковых расстояниях) подобраны по геометрии. Перед реальным использованием их нужно проверить на выборке людей и камер.

## API-ключи

**Не нужны.** Все модели работают локально. Интернет нужен один раз: скачать модели лица (~39 МБ, SHA-256 проверяется) и веса распознавания речи (~480 МБ для `small`, или `NS_ASR_MODEL=base` ~145 МБ).

Необязательные переменные:

| Переменная | Назначение |
|---|---|
| `NS_BIOMETRIC_KEY` | ключ Fernet для шифрования шаблонов лиц. Без неё ключ создаётся в `backend/data/biometric.key`; храните файл отдельно от базы |
| `NS_ASR_MODEL` | `tiny` / `base` / `small` / `medium` — размер модели распознавания речи |
| `NS_BIOMETRIC_MODEL_DIR` | папка моделей (по умолчанию `ml/biometric_models/`) |
| `NS_BIO_MAX_BODY_BYTES` | лимит размера запроса для фото и аудио (по умолчанию 24 МБ; для остального API — 256 КБ) |

## Как запустить и проверить каждую функцию

1. Windows: `run_windows.bat`. Скрипт ставит пакеты, faster-whisper, скачивает модели лица и сам открывает браузер. Linux/macOS: `./run.sh`.
2. **Центр безопасности** (`#/security`): все модели должны быть отмечены «работает», кроме детектора синтетического голоса.
3. **Проверка лица** (`#/face`):
   - «Включить камеру» → разрешить доступ;
   - «Проверка живости»: следуйте стрелкам → «Живой человек подтверждён»;
   - то же с фотографией на телефоне перед камерой → «НЕ пройдена» («голова не поворачивалась»);
   - после успешной проверки отметьте согласие → «Зарегистрировать лицо»;
   - новая проверка живости → «Сравнить с зарегистрированным» → совпадение. Другой человек → несовпадение, высокий риск.
4. **Проверка голоса** (`#/voice`): «Пример» → «Проверить» → высокий риск, подсвечены фразы. Запись с микрофона: скажите «служба безопасности банка, продиктуйте код из смс» → текст распознаётся, риск высокий. Обычная фраза → низкий.
5. **Общая проверка** (`#/combined`): подставляются последние проверки лица и звонка; выберите перевод → итог с результатами каждой проверки, причинами и рекомендациями.
6. **История** и **Конфиденциальность**: убедитесь, что в истории нет текста разговора; удалите шаблон; «Удалить все мои биометрические данные».

Автоматические проверки: `python -m unittest discover -s backend/tests -t .` (тесты с реальными моделями включаются, если модели скачаны и задан `NS_TEST_FACE_IMAGE`). В GitHub CI модели скачиваются, проверяются на реальном фото (OpenCV sample) и на речи (JFK sample из репозитория faster-whisper). Сквозной тест интерфейса `scripts/e2e_check.mjs` открывает все страницы с виртуальной камерой и микрофоном.

## Приватность (что гарантирует код)

- Фото, кадры и аудио не пишутся ни на диск, ни в базу: только декодирование в памяти.
- Шаблон лица сохраняется только при `consent: true` и текущей версии текста согласия. Регистрацию можно запретить целиком. Шаблон зашифрован; API никогда не возвращает шаблоны.
- В историю не попадают шаблоны, токены живости и цитаты из разговора (если хранение текста не включено).
- Изменения настроек, регистрации, удаления пишутся в журнал аудита (без данных).
- Заголовки: `Permissions-Policy: camera=(self), microphone=(self)`, CSP без внешних источников.
