# Аудит безопасности Android-приложения Saqtan (22.10.2026)

Проверены: исходный код `android/app`, `AndroidManifest.xml` (исходный и итоговый после сборки), Gradle-конфигурация, зависимости, сетевые запросы, локальное хранение, логи, экспортируемые компоненты, `PendingIntent`, релизный APK.

## Найденные проблемы и исправления

| # | Проблема | Риск | Исправление |
|---|---|---|---|
| 1 | Экспортируемая `MainActivity` выполняла команды из extras любого приложения: `start_listen` (включить анализ речи с микрофона), `start_video` (запустить запрос записи экрана) | Высокий | Команды принимаются только через неэкспортируемый `activity-alias` `InternalEntry`; внешние extras игнорируются; маршруты проверяются по списку. Проверяется на эмуляторе |
| 2 | Релизный APK подписывается демонстрационным ключом, который лежит в открытом репозитории с паролем `android` | Высокий (для публикации) | Сборка берёт ключ из секретов CI (`SAQTAN_KEYSTORE_*`), если владелец их добавил; без них сборка помечается как тестовая. Создать и хранить ключ должен владелец — не решено |
| 3 | Модель речи (нативные файлы для Vosk) скачивалась без проверки целостности и без ограничений размера (zip-бомба) | Средний | Проверка SHA-256 до распаковки, лимиты на размер скачивания, распакованного архива и число файлов, распаковка во временную папку, только HTTPS. CI при каждой сборке сверяет хэши с опубликованными файлами |
| 4 | Автоматический анализ речи был включён по умолчанию: микрофон включался после ответа незнакомцу без отдельного согласия | Средний | Выключен по умолчанию; включается в настройках после окна с объяснением. Микрофон не запрашивается в общем «Разрешить всё» |
| 5 | История хранилась бессрочно; удалённые записи SQLite оставались в свободных страницах файла; не было способа удалить все данные | Средний | Автоудаление через 90 дней, `PRAGMA secure_delete`, кнопка «Удалить все данные» (история, отметки, настройки, состояние звонка, ключ Keystore, уведомления, кэш) |
| 6 | Уведомления с номером и подробностями видны на заблокированном экране | Средний | `VISIBILITY_PRIVATE` и нейтральная публичная версия уведомления |
| 7 | Фрагменты разговоров (если пользователь включил их хранение) лежали в базе открытым текстом | Низкий | Шифрование AES-256-GCM ключом из Android Keystore; старые записи шифруются при запуске |
| 8 | Android 12+ переносил данные приложения на новый телефон (allowBackup=false этого не запрещает) | Низкий | `dataExtractionRules` (Android 12+) и `fullBackupContent` (Android 10–11): ничего не копируется ни в облако, ни при переносе |
| 9 | Не было явной сетевой конфигурации | Низкий | `network_security_config`: только HTTPS, только системные сертификаты |
| 10 | Пользователю показывался текст исключений (адреса, технические подробности) при ошибке скачивания модели | Низкий | Понятные сообщения без технических данных |
| 11 | В логе отчёта о звонке печатался заголовок отчёта | Низкий | Удалено; CI проверяет, что ни один вызов `Log` не выводит номер, текст SMS, расшифровку, код |
| 12 | `kaspi-bonus.top/verify` в коде | Информация | Это выдуманная фишинговая ссылка для демо-сценария и тестов; приложение её не открывает (нет WebView и автоссылок). Заменена на зарезервированный домен `kaspi-bonus.example`, который не может принадлежать никому |
| 13 | APK публиковался до проверки на эмуляторе; эмулятор не останавливал CI при провале проверок | Процесс | Публикация — отдельный шаг после эмулятора; любой `FAIL` останавливает CI. Это сразу поймало падение из-за `PRAGMA` в одной из промежуточных сборок |

Проверено и проблем не найдено: секретов, токенов и приватных ключей в коде и APK нет; все `PendingIntent` неизменяемые (`FLAG_IMMUTABLE`); `ContentProvider` нет; сервисы и приёмники защищены системными разрешениями (`BIND_SCREENING_SERVICE`, `BIND_NOTIFICATION_LISTENER_SERVICE`, `BIND_QUICK_SETTINGS_TILE`, `BROADCAST_SMS`); `PHONE_STATE` — защищённое системное событие; нет WebView, загрузки кода, `Runtime.exec`; SMS не сохраняются; камера и запись экрана — только по кнопке; блокировка звонков — только номеров, которые пользователь сам отметил, при включённой настройке.

## Автоматические проверки в CI (каждая сборка)

`android/ci/security_checks.py` и `android/ci/emulator_smoke.sh`:
- итоговый манифест: резервное копирование выключено, не отлаживаемый, HTTPS-конфигурация, все экспортируемые компоненты защищены, список разрешений совпадает с проверенным;
- релизный APK: поиск ключей, токенов, приватных ключей, удалённого тестового домена;
- исходный код: логи без персональных данных;
- зависимости: OSV.dev по фактическому `releaseRuntimeClasspath`;
- Android Lint, категория Security;
- эмулятор Android 14: внешнее приложение не может включить микрофон; `InternalEntry` недоступен извне; «Удалить все данные» очищает историю и настройки; при отозванных разрешениях звонок и SMS не приводят к падению; в логах приложения нет номеров и кодов.
