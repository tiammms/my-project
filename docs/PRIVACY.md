# Политика конфиденциальности Saqtan (Android)

Документ описывает фактическое поведение приложения в исходном коде этого репозитория. Если поведение меняется, этот документ меняется вместе с кодом.

## Какие данные обрабатываются и где

| Данные | Зачем | Где хранится | Срок |
|---|---|---|---|
| Номер входящего звонка, есть ли он в контактах | Оценить риск звонка до ответа | Только на телефоне | В истории предупреждений — до 90 дней; счётчик частых звонков — 1 час |
| Текст SMS | Найти одноразовый код во время звонка и признаки обмана | Нигде: анализ в памяти, текст не сохраняется | — |
| Код из SMS | Тревога «код во время звонка» | В истории только маска (например, 4••1) | До 90 дней |
| Уведомления WhatsApp/Telegram/Viber | Увидеть звонок через мессенджер и проверить текст сообщения | Текст не сохраняется; номер — в истории, если было предупреждение | До 90 дней |
| Звук с микрофона | Распознать речь на громкой связи | Нигде: звук обрабатывается моделью Vosk в памяти и не записывается | — |
| Звук для проверки «синтезированный ли голос» (экспериментально) | Предупредить, если голос похож на робота или ИИ | Нигде: фрагменты по 4 секунды оцениваются моделью на телефоне и сразу отбрасываются; в отчёт попадает только число фрагментов и сколько из них похожи на синтезированный голос | — |
| Запись разговора (только если пользователь включил «Записывать звонки») | Прослушать разговор с незнакомым номером позже | Только на телефоне, зашифрована (AES-256-GCM, отдельный ключ на каждую запись, ключ защищён Android Keystore) | 30 дней или до удаления |
| Фрагменты разговора | Показать, на какой фразе сработала проверка | Только если пользователь включил «Хранить фрагменты»; шифруются ключом Android Keystore | До 90 дней |
| Кадры камеры (проверка лица) и экрана (проверка видеозвонка) | Проверка живости по кнопке пользователя | Нигде: анализ ML Kit на телефоне, кадры не сохраняются | — |
| Отмеченные номера, настройки | Помнить решения пользователя | Только на телефоне | До удаления пользователем |

## Что приложение не делает

- Не отправляет данные на серверы: в приложении нет собственного сервера, аналитики, рекламы и трекеров.
- Интернет используется только для однократного скачивания модели распознавания речи по HTTPS с alphacephei.com; файл проверяется по SHA-256.
- Не включает камеру и запись экрана без нажатия кнопки пользователем; запись экрана каждый раз подтверждается системным окном Android.
- Не включает микрофон сам, если пользователь не включил «Автоанализ речи» или «Записывать звонки» и не подтвердил это. Пока микрофон работает или идёт запись, видно системное уведомление.
- Записывает разговор только при включённой настройке «Записывать звонки», только звонки с незнакомых номеров и только через микрофон (собеседник слышен на громкой связи): Android не даёт приложениям звук самого звонка. Записи не отправляются никуда; прослушать или удалить запись можно в отчёте о звонке.
- Проверка голоса работает только вместе с анализом речи или записью звонка (тот же микрофон, то же уведомление), не определяет личность и не говорит, мошенник ли человек: банки тоже звонят с синтезированным голосом. Модель встроена в приложение и проверяется по SHA-256 перед загрузкой.
- Не слышит звук звонков в мессенджерах: Android и мессенджеры не дают его сторонним приложениям.
- Не копирует данные в облачную резервную копию и на новый телефон.
- Не называет человека мошенником: показывает приём обмана и фразу, на которой сработала проверка.

## Управление данными

- «Настройки» → «Очистить историю угроз» — удаляет записи истории.
- «Настройки» → «Удалить все данные» — удаляет историю, записи разговоров, отмеченные номера, настройки, состояние текущего звонка и ключ шифрования. Удалённые записи базы перезаписываются (SQLite secure_delete).
- Модели речи удаляются на вкладке «Защита» (в них нет личных данных).
- Разрешения Android можно отозвать в настройках телефона; приложение продолжает работать без них, отключая соответствующую функцию.

## Разрешения

| Разрешение | Для чего | Когда запрашивается |
|---|---|---|
| Телефон, журнал вызовов | Состояние звонка и номер входящего (Android 9+ отдаёт номер только с журналом вызовов) | Модули «Определитель номера», «Состояние звонка» |
| Контакты | Не проверять звонки и сообщения знакомых | Модуль «Контакты» |
| Получение SMS | Код во время звонка | Модуль «Коды из SMS» |
| Микрофон | Анализ речи | Только модуль «Голосовой ИИ» |
| Камера | Проверка живости | Только кнопка на экране «Проверка лица» |
| Окно поверх других приложений | Предупреждение на экране звонка | Модуль «Окно поверх звонка» |
| Уведомления | Предупреждения и отчёты | Модуль «Уведомления» |
| Доступ к уведомлениям | Звонки и сообщения мессенджеров | Модуль «Мессенджеры» (системные настройки) |
| Интернет | Скачивание модели речи | Без запроса (обычное разрешение) |
