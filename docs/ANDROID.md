# NeuroShield AI для Android

Нативное приложение на Kotlin и Jetpack Compose, папка `android/`. Устанавливается через APK. Сайт и веб-интерфейс для него не нужны.

## Как получить и установить APK

1. Каждый push в `main` запускает GitHub Actions: тесты → сборка → публикация. Готовый APK лежит в релизе **android-latest**: репозиторий → **Releases** → `NeuroShieldAI-1.0.N.apk`.
2. Скачайте файл на телефон и откройте его. Android попросит разрешить установку из этого источника (браузера или «Файлов»).
3. Новые сборки подписаны тем же демо-ключом, поэтому ставятся поверх старой версии.

Собрать самому: Android Studio → Open → папка `android` → Build → Build APK(s). Или командой `./gradlew assembleRelease`, нужны JDK 17 и Android SDK 35.

## Первая настройка (вкладка «Защита»)

| Разрешение | Зачем | Без него |
|---|---|---|
| Роль «Определитель номера и защита от спама» | оценить номер до ответа | предупреждение придёт, только когда телефон уже звонит, через состояние звонка |
| Телефон и журнал звонков | знать, что идёт разговор, и номер звонящего | нет защиты во время звонка |
| Контакты | не беспокоить при звонках знакомых | любой номер считается незнакомым |
| SMS | заметить код, пришедший во время разговора | нет главной защиты |
| Поверх других приложений | показать «⚠️ ВНИМАНИЕ! ВОЗМОЖНО, МОШЕННИК!» прямо на экране звонка | только уведомление |
| Уведомления | предупреждения и кнопка «Слушать звонок» | — |
| Микрофон + модель речи (45 МБ, скачивается один раз) | анализ речи через громкую связь | анализ речи недоступен |

## Что делает приложение и насколько это надёжно

| Функция | Как | Надёжность |
|---|---|---|
| **Оценка входящего номера** | `CallScreeningService`: нет в контактах, скрытый, международный, звонит 3+ раз за час, номер отмечен вами. Звонок никогда не блокируется | работает; номер сам по себе не доказывает мошенничество, поэтому уровни осторожные |
| **Код из SMS во время звонка с незнакомым номером** | `SMS_RECEIVED` + состояние звонка → красное окно поверх экрана звонка и вибрация | работает на любом телефоне с выданными разрешениями. Главная функция |
| **Подозрительное SMS** | тот же анализатор фраз; ссылки, «карта заблокирована» и т. п. | работает |
| **Анализ речи собеседника** | громкая связь → микрофон → **Vosk** (офлайн-распознавание, Kaldi) → анализатор фраз → предупреждение при росте риска | **Зависит от телефона.** С Android 10 приложениям запрещено получать звук звонка (`VOICE_CALL`), поэтому слышно только через громкую связь. Часть прошивок отдаёт приложениям тишину во время звонка: приложение это определяет за 6 секунд и пишет об этом. **Пока не проверено на реальных телефонах** |
| **Проверка текста** | вставить SMS или реплики звонящего | работает |
| **Проверка лица (живость)** | CameraX + **Google ML Kit Face Detection** (модель внутри приложения): случайный порядок поворотов головы и моргание, одно лицо, то же лицо всё время | работает офлайн. Не определяет, *кто* перед камерой, и не защищает от 3D-маски и подмены камеры |
| История | SQLite на телефоне; звук и тексты SMS не хранятся, фрагменты разговоров — только если включить | работает |

**Анализатор фраз** (`core/ScamAnalyzer.kt`) — прозрачные правила, без обученной модели. Те же 7 категорий, что на сервере NeuroShield, плюс «подозрительная ссылка». Языки: русский, казахский, английский. Одна тактика не даёт высокий риск. По звучанию голоса человек мошенником не называется.

**Чего нет:**
- детектора синтезированного (клонированного) голоса: проверенной открытой модели для телефона нет;
- распознавания личности по лицу: на телефоне нет модели распознавания лиц. Её можно подключить через сервер NeuroShield (`/api/v1/bio/face/*`).

## Сервер, ключи, интернет

- **Сервер не нужен.** Всё работает на телефоне.
- **API-ключи не нужны.**
- **Интернет** нужен только для одной загрузки модели речи с alphacephei.com: русская 45 МБ, казахская 42 МБ, английская 40 МБ.
- Для Google Play пришлось бы получить разрешение Google на SMS и журнал звонков и подписать приложение своим ключом. Демо-ключ в репозитории для этого не годится.

## Что проверяют автотесты

`app/src/test/.../CoreLogicTest.kt` (JUnit, 23 теста) — запускаются в CI при каждой сборке:
- анализатор фраз (тексты мошенников и обычные, ru/kk/en, текст без пунктуации, как выдаёт распознавание);
- оценка номера;
- поиск кодов в SMS;
- логика проверки живости: фото, неверный порядок поворотов, подмена лица;
- рост риска во время разговора (без повторных окон);
- распознавание «тишины» микрофона.

На реальном телефоне нужно проверить вручную:
1. Звонок с незнакомого номера → окно до ответа.
2. Во время разговора отправьте себе SMS «Код 1234» с другого телефона → красное окно.
3. Громкая связь → «Слушать звонок» → собеседник говорит «служба безопасности банка, продиктуйте код из смс» → предупреждение. Если появится «телефон отдаёт тишину», на этой модели телефона функция недоступна.
4. Проверка лица: живой человек проходит, фото на экране другого телефона — нет.
