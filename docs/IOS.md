# NeuroShield AI для iPhone

Нативное приложение на Swift и SwiftUI (iOS 16+), папка `ios/`. Проект Xcode создаётся из `ios/project.yml` (XcodeGen).

## Что умеет

| Функция | Как работает | Проверено |
|---|---|---|
| Проверка текста и ссылок | Те же правила, что в Android-версии и на сервере (русский, казахский, английский); поддельные сайты банков, короткие ссылки, IP-адреса, punycode | юнит-тесты в симуляторе (CI) |
| Фильтр SMS от незнакомцев | Расширение Message Filter: SMS и iMessage с высоким риском уходят в «Нежелательные» | собрано; в симуляторе SMS не приходят — на телефоне не проверено |
| Метки и блокировка номеров | Расширение Call Directory: номера, отмеченные вами, подписываются при звонке и (если включено) сбрасываются | собрано; на телефоне не проверено |
| Проверка живости | Apple Vision: поворот головы в одну сторону, затем в другую (фото так не может) | в симуляторе нет камеры — на телефоне не проверено |
| Демо-показ | Сценарий звонка мошенника по шагам; ввод выдуман, оценки настоящие | симулятор (CI), скриншоты в ветке `ci-screens-ios` |
| История, «Поделиться», экстренные звонки близкому и в банк | Хранится только на iPhone | симулятор |

## Чего iPhone не позволяет (для всех приложений)

- слышать телефонные звонки и звонки в WhatsApp;
- показывать окно поверх экрана звонка;
- читать SMS от контактов и коды во время звонка;
- оценивать номер незнакомца до ответа (Call Directory даёт только метки из заранее заданного списка).

Поэтому анализ звонка в реальном времени, окно поверх звонка и тревога «код из SMS во время звонка» есть только в Android-версии.
В демо-режиме iPhone эти шаги показаны на учебных данных, с пометкой.

## Как установить на iPhone

Готового файла для установки, как APK у Android, у iPhone нет: Apple разрешает ставить приложения только с подписью.

1. Нужен Mac с Xcode 16 и бесплатный Apple ID.
2. `brew install xcodegen && cd ios && xcodegen`, открыть `NeuroShield.xcodeproj`.
3. В каждой цели (NeuroShield, MessageFilter, CallDirectory) выбрать свою команду в Signing & Capabilities.
   App Group `group.ai.neuroshield.app` нужен для обмена отмеченными номерами между приложением и расширением.
4. Подключить iPhone, включить на нём «Режим разработчика», нажать Run.
   С бесплатным Apple ID приложение работает 7 дней, затем его нужно установить заново.
   Для раздачи через TestFlight нужен платный аккаунт Apple Developer ($99 в год).
5. На iPhone включить: Настройки → Приложения → Сообщения → Неизвестные и спам → NeuroShield;
   Настройки → Приложения → Телефон → Блокировка и идентификация вызовов → NeuroShield.

## Сборка и проверка в CI

Задача `ios` в `.github/workflows/ci.yml` (macOS): генерирует проект, запускает юнит-тесты, собирает приложение для симулятора,
запускает его и снимает экраны (`ios/ci/screens.sh`). Скриншоты публикуются в ветку `ci-screens-ios`.
